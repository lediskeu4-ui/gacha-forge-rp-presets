# Gacha Forge RP Presets — 실험판 0.1.0

Marinara에 저장한 RP 프롬프트 프리셋을 Gacha Forge 1.8.13의 스토리 서술·캐릭터 채팅에 연결하는 비공식 런타임 패치입니다. GitHub 저장소에 이 폴더의 파일을 올려 배포할 수 있습니다. 원본 가챠포지 코드와 개인 프리셋은 포함하지 않습니다.

## 기능

- 가챠포지 안의 `RP 프리셋` 버튼으로 기존 마리나라 프리셋 선택
- 월드별 설정 저장, 스토리 서술/캐릭터 채팅 각각 적용
- 마리나라의 프리셋 조립기 사용: 섹션·그룹·프리셋 기본 선택값 처리
- 가챠포지의 기존 생성 메시지와 출력 형식 지침 유지
- 선택한 프리셋은 매 요청에 다시 읽어 수정 내용 반영
- 사용 안 함 선택 및 제거 지원

## 설치 전

**실제 Marinara/폰에서 통합 검증되지 않은 실험판입니다.** 구문 검사와 모의 런타임 검증만 수행했습니다. 먼저 마리나라의 백업 기능으로 데이터를 백업하세요. 다른 패치와의 병용 및 Engine 내부 API의 버전 호환성은 검증하지 못했습니다.

지원 대상은 Gacha Forge **1.8.13**과 `packages/server/dist`에 `getDB`, `createPromptsStorage`, `assemblePrompt` 모듈을 제공하는 Engine입니다. 공식 확장 API만으로 프리셋 조립기를 호출할 수 없어 Engine 내부 모듈을 읽습니다. Engine/가챠포지 업데이트 시 호환 확인이 필요합니다. API 이름만 같고 인자 구조가 달라지는 경우는 설치 검사로 발견하지 못할 수 있습니다.

## Termux 설치

1. 이 프로젝트 폴더를 `~/gacha-forge-rp-presets`에 놓습니다. GitHub에 올린 뒤에는 자신의 실제 저장소 URL로 clone할 수 있습니다.
2. 마리나라가 실행 중인 터미널에서 Ctrl+C로 종료합니다.
3. 아래를 실행합니다.

```bash
cd ~/gacha-forge-rp-presets
node install.mjs ~/Marinara-Engine
```

4. 평소대로 실행합니다.

```bash
cd ~/Marinara-Engine
./start-termux.sh
```

5. 컴퓨터/폰 브라우저를 강력 새로고침하고 가챠포지 월드에 들어갑니다. 오른쪽 위 `RP 프리셋`을 누르고 프리셋·적용 대상을 고른 뒤 저장합니다.

LAN 접속은 마리나라의 Admin Access 설정이 필요합니다. 이 패치는 인증을 우회하거나 인증 정보를 저장하지 않습니다.

## 적용 범위와 제한

- 기존 스토리/채팅을 수정하지 않고 다음 생성에 반영됩니다.
- 별도 RP 채팅의 기록·캐릭터 카드·로어북·에이전트·고급 메모리·정규식·모델 파라미터는 가져오지 않습니다.
- 유저 정보는 가챠포지 주인공에서 제공됩니다. `{{char}}` 같은 카드 의존 매크로는 가챠포지 캐릭터에 자동 매핑하지 않습니다. 캐릭터 정보가 필요한 프리셋은 빈 내용 또는 의도와 다른 결과를 낼 수 있습니다.
- 선택형 항목은 프리셋의 기본값을 사용합니다. 이 화면에서 항목별 선택을 편집하는 기능은 없습니다.
- 가챠포지 내부의 narration/chat 작업 분류를 따릅니다. 같은 chat 분류를 쓰는 채팅 메모리 작업에도 적용될 수 있습니다. 게임 구조 데이터 생성(structured)·압축(compress)에는 적용하지 않습니다.
- 프리셋이 강하게 다른 출력 형식을 요구하면 모델이 게임 형식을 깨뜨릴 수 있습니다. 이때 사용 안 함으로 돌리세요.
- 프리셋이 삭제되거나 조립에 실패하면 해당 생성을 중단합니다. 실패를 숨기고 프리셋 없이 생성하지 않습니다.
- 디버그 모드에서는 최종 조립 프롬프트가 서버 디버그 로그에 기록될 수 있습니다.
- 기존 지연/CG/한국어 패치는 파일을 통째로 복원하지 않는 한 유지하지만, 패치 간 통합 실행은 미검증입니다. 시작 스크립트가 원본 파일을 재생성하면 이 패치가 사라질 수 있습니다.

## 제거

마리나라를 종료한 다음:

```bash
cd ~/gacha-forge-rp-presets
node install.mjs ~/Marinara-Engine --uninstall
```

마리나라를 다시 시작하고 강력 새로고침합니다. 설치 직전 파일은 `~/Marinara-Engine/gacha-rp-presets-backup-1.8.13`에 있습니다. 설치 후 다른 패치가 파일을 수정했다면 제거기는 덮어쓰기를 거부합니다. 백업에 있는 `server.mjs`, `client.js`, `manifest.json`을 직접 비교해 복원하세요. 저장된 월드별 선택과 미사용 helper는 남겨두며 게임 저장 데이터를 삭제하지 않습니다.
